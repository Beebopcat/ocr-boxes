# Security policy

## Report a problem privately
Use GitHub private vulnerability reporting: https://github.com/Beebopcat/ocr-boxes/security/advisories/new
(or the "Report a vulnerability" button on this repository's Security tab).
Please do not open public issues or pull requests for security problems, and do not share details publicly until a fix is out.

## What to include
What you found, where (file or page), how to reproduce it, and what you think the impact is.

## Scope
This repository's code and its published demo page, if any. Third-party components belong to their own projects.

## What to expect
This is a one-person project. Reports are read and answered as time allows, with no guaranteed timeline. There is no bug bounty.
